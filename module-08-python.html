29.1 — Syntaxe de base

nom = "Marie"                 # chaîne de caractères
age = 28                      # entier
actif = True                  # booléen

if age >= 18:
    print(f"{nom} est majeure")
else:
    print(f"{nom} est mineure")

for i in range(5):
    print(f"Itération {i}")

Contrairement à PowerShell ou Bash, Python utilise l'indentation pour délimiter les blocs de code — pas d'accolades ni de end. C'est strict, mais ça force un code lisible par construction.

29.2 — Listes et dictionnaires

serveurs = ["SRV01", "SRV02", "SRV03"]          # liste ordonnée
config = {"nom": "SRV01", "ram_go": 16, "actif": True}   # dictionnaire clé-valeur

for serveur in serveurs:
    print(f"Vérification de {serveur}")

print(config["ram_go"])   # accès par clé

Le dictionnaire Python joue le même rôle que l'objet PowerShell ou le JSON — une structure clé-valeur omniprésente dans le développement moderne, y compris pour manipuler les réponses d'API (semaine 31).

29.3 — Lecture/écriture de fichiers CSV

import csv

with open("serveurs.csv", "r", encoding="utf-8") as f:
    lecteur = csv.DictReader(f)
    for ligne in lecteur:
        print(ligne["nom"], ligne["ram_go"])

Le mot-clé with garantit que le fichier se ferme correctement même en cas d'erreur — un réflexe de robustesse, dans le même esprit que le Try/Catch/Finally de PowerShell.

30.1 — Fonctions et modules

def calculer_age(date_achat, aujourdhui):
    """Retourne l'âge en années entre deux dates."""
    return (aujourdhui - date_achat).days // 365

# Dans un fichier séparé outils.py, puis :
from outils import calculer_age

Comme pour les modules PowerShell (Module 7) ou Bash (Module 3), séparer le code en fichiers réutilisables évite la duplication et facilite la maintenance à mesure que les scripts grandissent.

30.2 — Gestion des exceptions

try:
    with open("config.csv", "r") as f:
        contenu = f.read()
except FileNotFoundError:
    print("Fichier de configuration introuvable — utilisation des valeurs par défaut")
except Exception as e:
    print(f"Erreur inattendue : {e}")
finally:
    print("Traitement terminé")

Même logique que le Try/Catch/Finally PowerShell (Module 7) : capturer des erreurs spécifiques (ici FileNotFoundError) plutôt qu'une exception générique donne un message utile et une réaction adaptée à chaque situation.

30.3 — Automatisation système avec os/subprocess

import os
import subprocess

for fichier in os.listdir("."):
    print(fichier)

resultat = subprocess.run(["ping", "-c", "4", "8.8.8.8"], capture_output=True, text=True)
print(resultat.stdout)

subprocess permet à Python d'exécuter n'importe quelle commande système (y compris des scripts Bash ou des cmdlets PowerShell) et de récupérer sa sortie — un pont pratique entre les trois langages de ce parcours.

31.1 — Requêtes API REST

import requests

reponse = requests.get("https://api.github.com/users/octocat")
if reponse.status_code == 200:
    data = reponse.json()
    print(data["name"], data["public_repos"])
else:
    print(f"Erreur : {reponse.status_code}")

Presque tous les services modernes (GitHub, Microsoft Graph vu au Module 7, services météo, tickets) exposent une API REST. Le module requests est l'outil standard pour les consommer depuis Python — vérifier systématiquement le status_code avant de traiter la réponse est un réflexe de robustesse essentiel.

31.2 — Scraping web responsable

Scraping web

Extraction automatisée de données depuis une page web, avec la bibliothèque BeautifulSoup notamment. À utiliser avec discernement : respecter le fichier robots.txt du site, limiter la fréquence des requêtes, et préférer une API officielle quand elle existe.

31.3 — Connexion à une base de données SQLite

import sqlite3

conn = sqlite3.connect("inventaire.db")
cur = conn.cursor()
cur.execute("CREATE TABLE IF NOT EXISTS equipements (nom TEXT, ram_go INTEGER)")
cur.execute("INSERT INTO equipements VALUES (?, ?)", ("SRV01", 16))
conn.commit()

for ligne in cur.execute("SELECT * FROM equipements"):
    print(ligne)
conn.close()

SQLite est une base de données légère, contenue dans un simple fichier — idéale pour des scripts d'automatisation qui doivent stocker un historique sans monter un vrai serveur de base de données.

32.1 — pandas : manipulation de données tabulaires

import pandas as pd

df = pd.read_csv("inventaire.csv")
print(df.head())                          # aperçu des 5 premières lignes
print(df.describe())                      # statistiques descriptives

actifs = df[df["statut"] == "actif"]       # filtrage
par_service = df.groupby("service")["valeur"].sum()   # agrégation

pandas est l'outil de référence pour manipuler des données tabulaires en Python — le CSV devient un objet DataFrame puissant, avec filtrage, agrégation et jointures bien plus riches que les listes/dictionnaires manuels de la semaine 29.
