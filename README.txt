SYNCHRONISATION AVEC LE PLANNER (badges "Terminé")
----------------------------------------------------
Deux façons de faire fonctionner les badges de progression dans le manuel :

1) HÉBERGEMENT PARTAGÉ (recommandé, automatique)
   Si tu héberges ce dossier complet sur un même site (GitHub Pages, Netlify...),
   le manuel lit directement la progression de l'app en temps réel — aucune
   action requise. Testé et validé.

2) FICHIERS LOCAUX (file://), sans hébergement
   Le navigateur isole chaque fichier local : pas de synchro automatique.
   Utilise le bouton "Importer ma progression" en haut du manuel, en
   sélectionnant le fichier JSON exporté depuis l'app (bouton "Exporter la
   progression" dans le menu de l'app). Testé et validé.
